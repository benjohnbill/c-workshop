# Codex instructions

Before work, read [the workspace instructions](../AGENTS.md), then
[the local tutor instructions](CLAUDE.md). Resolve both links from this file's
directory. Read [the curriculum](CURRICULUM.md) when stage scope or completion
matters. On re-entry, read only the latest entry in
[the learning log](LEARNING_LOG.md) unless the request needs older evidence.

This directory is an independent Git repository. Run builds and Git commands
here, preserve learner work, and stage only paths for the requested task. The
parent repository ignores this directory and does not own its history.

The exercise briefs are specifications. Source files are the learner's work.
Do not create solution code, source scaffolds, or hidden answer files unless the
user directly requests them. Append learning evidence only at a passed stage or
an explicitly declared session close.
